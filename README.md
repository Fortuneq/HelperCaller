# HelperCaller - ИИ-помощник для телефонных продаж

🎯 Система в реальном времени для генерации подсказок операторам продаж

## Быстрый старт

```bash
# Установка зависимостей
pip install torch openai-whisper openai pyaudio

# Обработка аудио файла
python main.py audio_file.wav

# Режим реального времени  
python main.py --realtime
```

## Возможности

- ⚡ **Быстрая генерация подсказок** (~1.5 секунды)
- 🎤 **Распознавание речи** (Whisper)
- 👥 **Определение ролей** (Менеджер/Клиент)
- 🔄 **Режим реального времени**
- 📊 **Умные подсказки** на основе контекста диалога

## Архитектура пайплайна

```
Аудио → Whisper → Определение ролей → GPT-4o → Подсказки
```

1. **Подготовка аудио** (01_prepare_audio.py)
2. **Транскрипция** (02_transcribe.py) 
3. **Определение ролей** (03_label_roles.py)
4. **Генерация подсказок** (04_coach_replies.py)

## Основные файлы

- `main.py` - Упрощенный интерфейс
- `helper_caller_pipeline.py` - Единый пайплайн 
- `realtime_assistant.py` - Режим реального времени
- `USAGE.md` - Подробная документация

## Пример подсказок

```json
{
  "сейчас": ["Активно слушайте клиента"],
  "скоро": ["Уточните потребности"],
  "позже": ["Предложите демо"],
  "возражения": ["Покажите понимание проблемы"]

```

## Производительность

- **Транскрипция**: ~0.3с на сегмент
- **Генерация подсказок**: ~1.5с
- **Модели**: Whisper (tiny/base), GPT-4o-mini

## Техническое задание

Система ИИ-помощника для операторов продаж:
- Распознавание речи в реальном времени
- Генерация контекстных подсказок
- Интеграция с БД клиентов (планируется)
- Время отклика: ~1.5 секунды
